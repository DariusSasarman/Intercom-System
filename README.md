# Intercom-System

## What is it?

An arduino-based system that uses a locking mechanism to secure the access of any establishment it is attatched onto.

## How does it look?

[demo.webm](https://github.com/user-attachments/assets/451ec117-a81c-42fa-a622-cfcbd7621dfa)

## How does the locking mechanism work?

[locking.webm](https://github.com/user-attachments/assets/e044cf7d-d4b4-4e34-b787-5abd2ca2e74a)

It's a modified mechanical component attatched to an electonically-controlled step-motor.
